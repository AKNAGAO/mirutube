# MiruTube

ブラウザだけで動く動画共有アプリのプロトタイプです。`index.html` をブラウザで開くだけで使えます（インストール不要）。

## 主な機能

- 動画のアップロード（ドラッグ&ドロップ、サムネイル自動生成）
- ホーム一覧・検索・チャンネルページ
- 再生ページ（高評価、チャンネル登録、コメント、関連動画の自動再生）
- ショート動画（縦スクロールフィード）
- 再生リスト・後で見る
- 通知、再生履歴、ダークモード
- 初回起動時にサンプル動画を自動生成（Canvas で描画したオリジナル映像）

## データの保存先

動画やコメントなどのデータはブラウザ内（IndexedDB）に保存されます。
他の端末やブラウザとは共有されません。
